## The learning path

**Swings → structure → liquidity and ranges → zones → bias → confirmation → one model → testing.**

Each lesson includes an outcome, six study steps, original source links, chart drills, a mastery question and completion boxes. New readings are labeled separately. You do not need to read every linked article.

The workbook suggests **8–11 hours per week**. Its chart quotas can take longer, especially for a beginner: treat the weeks as learning blocks, and extend to **12–16 weeks** when needed. Then allow the separate **four-week paper-trading phase**, extending it if the sample is sparse. Course completion is a learning milestone, not evidence of profitability.
