## Outcome

Test a Candle Range Theory sequence while leaving TBS rules explicitly provisional.

## Study in order

1. Study the CRT idea: a meaningful anchor candle defines a high-low range for subsequent price action.
2. Define a sweep beyond the anchor high/low and a close back inside the range; distinguish this from a sustained breakout.
3. Add optional lower-timeframe MSS/FVG confirmation only if you define it in advance; note changes in missed signals.
4. Measure the distance from entry to structural invalidation and to the opposing part of the anchor range.
5. Treat "TBS" as a course-specific add-on until its explicit trigger and invalidation are known.
6. Test the stand-alone CRT framework before attributing any improvement to the extra TBS condition.
