## Outcome

Finalize one testable playbook and begin a structured simulated performance sample.

## Study in order

1. Complete the remaining screenshot labels: Fixed TCiC, 2s CiC, Fixed QT Relation, Liquidity Purge and Liquidity Pool entries.
2. Write a source-status note for each unusual term. If it is instructor-specific, treat the matching public concept as only an approximation.
3. Choose a final model using five criteria: clarity, repeatability, market fit, realistic stops and sufficient opportunities.
4. Specify stop placement, target logic, estimated costs, maximum simultaneous exposure and a daily stop condition.
5. Design a blind historical test and a separate simulated forward test; do not change rules during either sample.
6. Evaluate the system using expectancy, drawdown, missed signals, false positives and checklist adherence, then revise only between samples.

- [ ] Finalize a one-page trading playbook and 20-30 historical entries.
- [ ] Begin a separate 4-week paper-trading log; retain losing and missed examples.
- [ ] Complete a post-test review: continue, refine once, or abandon the setup.

## Mastery check

Can you state all model conditions in fewer than eight unambiguous rules?

**Watch for:** Neither finishing the 26 classes nor finding a high historical win rate justifies live leveraged trading.
