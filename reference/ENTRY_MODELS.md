## Definition status

Use **defined** only when you can write context, trigger, invalidation, target and expiry. Use **partially mapped** when public teaching covers only part of the named setup. Use **undefined** for missing instructor rules. A familiar acronym is not sufficient evidence.

Do not expand TBS, TWS, AO-X, CiC, TCiC, PSB, MCS/WCS/DCS/SCS/MSCS, OC or the named fixed variations by guessing. In lesson 22, SD as standard-deviation projections is a possible public match, not a confirmed instructor definition.

For each family, duplicate the [entry card](../templates/ENTRY_CARD.md) and record the exact source. Keep undefined models in the catalog while you test a fully defined alternative.
