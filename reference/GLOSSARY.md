# Glossary

[Roadmap](../SOLO_LEARNING_ROADMAP.md) · [Concept note](../templates/CONCEPT_NOTE.md)

Definitions below come from DOCX Appendix D. They are working vocabulary; write the operational rule and source used in your own sample.

| Term | Workbook definition |
|---|---|
| BOS | Break of Structure; a trend-continuation break under the chosen structural rule. |
| CHoCH | Change of Character; a countertrend structural change; precise rules vary. |
| MSS | Market Structure Shift; a structural break, often paired with displacement. |
| IDM | Inducement; a smaller swing/level interpreted as potential liquidity. Not universally defined. |
| BSL / SSL | Buy-side / sell-side liquidity; hypotheses about stops above highs / below lows. |
| IRL / ERL | Internal / external range liquidity; levels inside vs. outside a defined range. |
| FVG / iFVG | Fair Value Gap / inversion FVG; a three-candle gap and its later invalidation/role change. |
| OB / BB / MB | Order block / breaker block / mitigation block; educator-specific zone rules. |
| POI | Point of Interest; a zone to monitor rather than an entry signal by itself. |
| STH/STL | Short-term high/low; local pivot, commonly using a three-candle rule. |
| ITH/ITL | Intermediate-term high/low; a hierarchy of short-term pivots. |
| EQ / P&D | Equilibrium / premium-and-discount; midpoint and halves of a chosen range. |
| CISD | Change in State of Delivery; candle-delivery confirmation in ICT-style teaching. |
| AMD / PO3 | Accumulation, Manipulation, Distribution / Power of Three; a proposed price narrative. |
| OTE | Optimal Trade Entry; commonly taught Fibonacci retracement zone around 62%-79%. |
| CRT | Candle Range Theory; sweep and reclaim of an anchor candle's range; multiple variants. |
| QML | Quasimodo Level; reversal sequence with higher-high/lower-low or mirrored structure. |
| QT | Quarterly Theory; four-part time-cycle labels that require independent testing. |
| TBS / TWS / AO-X / CiC | Terms appearing in the course list; obtain the instructor's definition before using them. |

## Added study vocabulary

| Term | Meaning in this roadmap |
|---|---|
| HTF / LTF | Higher / lower timeframe relative to your chosen chart pairing. |
| PD arrays | ICT-style name for price zones or reference structures; define each type separately. |
| Displacement | A directional price expansion. Specify your own measurable body, range or close criteria before testing. |
| R | A fixed initial planned risk amount for a trade; net R is net P&L divided by that amount. |
| Look-ahead bias | Using information that would not yet have been available at the decision time. |
| Evaluation sample | A reserved period evaluated after rules are frozen; revising rules against it consumes its independence. |

The last two terms are added research vocabulary; see [QuantStart](../resources/README.md#n09) and the [testing protocol](../practice/TESTING.md).
