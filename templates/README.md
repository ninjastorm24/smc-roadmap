# Copyable study templates

[Roadmap](../SOLO_LEARNING_ROADMAP.md) · [Setup](../practice/SETUP.md)

Copy a template into your personal study log before filling it. Keep the blank originals for reuse.

| Template | Use it when | Based on |
|---|---|---|
| [Concept note](CONCEPT_NOTE.md) | Learning each new definition | Workbook lessons; expanded from the original Markdown |
| [Session plan](SESSION_PLAN.md) | Before replay or a forward session | DOCX Appendix B daily-bias sheet |
| [Entry card](ENTRY_CARD.md) | Defining or auditing a candidate model | DOCX Appendix B entry card; expanded execution fields |
| [Trade journal](TRADE_JOURNAL.md) | Recording an opportunity and outcome | DOCX suggested journal fields and Appendix C |
| [Weekly review](WEEKLY_REVIEW.md) | Deciding whether to repeat or progress | DOCX weekly checks and Appendix C |

Use separate folders for observations, development tests, evaluation tests and forward simulation. An incomplete card can remain in your catalog; only a fully defined card can be a frozen test model.
